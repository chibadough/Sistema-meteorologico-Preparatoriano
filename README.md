# Sistema-meteorologico-Preparatoriano

## Español

Código de la estación meteorológica **Balun Canán** ubicada en Comitan de Dominguez.

### ¿Qué hace este proyecto?

Este proyecto contiene el código y la estructura base para una estación meteorológica preparatoriana capaz de recopilar, procesar y visualizar datos ambientales en tiempo real.  
La estación puede medir variables como:

- Temperatura
- Humedad
- Presión atmosférica
- Altitud aproximada
- Movimiento e inclinación
- Otras variables dependiendo de los sensores instalados

El sistema está pensado para proyectos educativos STEM, investigación escolar y monitoreo climático local.

---

### ¿Por qué este proyecto es útil?

Este proyecto es útil porque permite a estudiantes y entusiastas de la tecnología aprender sobre:

- Electrónica y sensores
- Programación con Arduino
- Recolección de datos meteorológicos
- Sistemas embebidos
- Análisis ambiental y climático

Además, fomenta el desarrollo de proyectos científicos y tecnológicos dentro del nivel preparatoria.

---

### ¿Cómo pueden comenzar los usuarios con el proyecto?

Para comenzar con el proyecto se recomienda:

1. Clonar este repositorio.
2. Instalar el IDE de Arduino.
3. Descargar las librerías necesarias para los sensores utilizados.
4. Conectar los módulos y sensores según el esquema del proyecto.
5. Cargar el código a la placa Arduino o microcontrolador correspondiente.
6. Abrir el monitor serial para verificar el funcionamiento de la estación.

---

Si tienes dudas o problemas con el proyecto puedes:

- Revisar la documentación y comentarios del código.

---

### ¿Quién mantiene y contribuye con el proyecto?

Este proyecto es mantenido por estudiantes y colaboradores relacionados con la estación meteorológica **Balun Canán**.

Las contribuciones son bienvenidas para:

- Mejorar el código
- Optimizar sensores

## English

Code for the **Balun Canán** weather station located in Comitan de Dominguez.

### What does this project do?

This project contains the code and base structure for a high school weather station capable of collecting, processing, and displaying real-time environmental data.  
The station can measure variables such as:

- Temperature
- Humidity
- Atmospheric pressure
- Approximate altitude
- Motion and inclination
- Other variables depending on the installed sensors

The system is designed for STEM educational projects, school research, and local climate monitoring.

---

### Why is this project useful?

This project is useful because it allows students and technology enthusiasts to learn about:

- Electronics and sensors
- Arduino programming
- Meteorological data collection
- Embedded systems
- Environmental and climate analysis

It also encourages the development of scientific and technological projects at the high school level.

---

### How can users get started with the project?

To get started with the project:

1. Clone this repository.
2. Install the Arduino IDE.
3. Download the required libraries for the sensors used.
4. Connect the modules and sensors according to the project setup.
5. Upload the code to the Arduino board or corresponding microcontroller.
6. Open the serial monitor to verify the weather station's operation.
